    어제 복습했던 코드
  1. mv 무빙 이동
  2. rm 리무브 삭제
  3. cp 카피 복사
  4. cd 시디 이동
  5. mkdir 엠케이디이아이 파일 만들기
  6. touch 터치 문서 만들기
  7. git add "옮기고 싶은 것 파일 이름 정확하게 적기(day01 또는 day02)"
  8. git commit -m "기억하기 좋은 이름 정하고 적기(good day 또는 say something)"
      9. 주의:commit로 막 누르는 순간 알수 없는 페이지(사실은 편집창)가 뜹니다. 그럴땐 shift+;(semicolon) 같이 누른 뒤 :q로 누르면 빠져나갈수 있다.
  9. git push
      10. 추신:그럼 github로 업로드 되어 저장할수 있습니다.
