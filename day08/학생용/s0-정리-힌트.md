# everyday 폴더 정리: day01~day08 → s0/

**8일차 마지막**, 0단계 돌아보기를 커밋한 뒤에 한다. `TIL.md`는 옮기지 않는다.

1. 시작 전 상태 확인
   cd /c/study/everyday
   git status          → working tree clean 이어야 한다 (아니면 먼저 커밋)
   ls                  → 실제로 있는 day 폴더 이름 확인 (빠진 날이 있을 수 있다)

2. s0 폴더를 만들고, 일자 폴더를 git mv로 옮긴다 (ls에서 본 이름만 적는다)
   mkdir s0
   git mv day01 day02 day03 day04 day05 day06 day07 day08 s0/
   (TIL.md는 적지 않는다)

3. 확인
   git status          → renamed: day01/... -> s0/day01/... 로 보이면 성공
   ls; ls s0

4. 커밋·push
   git commit -m "s0: 0단계 일자 폴더를 s0/ 아래로 정리"
   git push

5. GitHub에서 everyday 첫 화면: s0 폴더와 TIL.md

다음 단계부터 실습 폴더는 s1/day01, s1/day02, … (1단계)

막히면
- fatal: bad source …   → 없는 폴더 이름을 적었다. ls로 다시 보고 그 이름만. (아무것도 옮겨지지 않았으니 고쳐서 다시)
- mv로 옮겨 버렸다      → git add -A 로 올리면 Git이 대부분 "옮김(renamed)"으로 알아본다
- TIL.md는 옮기지 않는다 (everyday 맨 위에 그대로)
